## Built: Standards in operation: scope, champion, Create cycle (TASK-086)

| Area | What works | Roadmap / tasks |
|---|---|---|
| **Scope and champion** | Quality Management has a Standards tab with the institution's standards; the ⋯ menu of an IQF standard, sub-standard or item, and of any external requirement, is Link evidence, Assign scope, Assign champion, Create cycle (Request evidence left the IQF menu: evidence is requested through cycles). A scope is a level (Institution, Unit, Program, Course placeholder, or a custom one from Settings -> Organization -> Institution -> Scope levels) and optionally a list of units or programs; a champion is overall or per scoped item. Both cascade down the standard and, for an external requirement, through its approved mappings (scopes united; the champion only when the mapped items agree, otherwise "Needs a champion"); each value shows where it comes from ("Own", "From Standard 4", "From IQF 4.2"), an override can be set at any level and "Back to inherited" removes it. They live outside the frozen versions, so they change on published versions and carry to new ones. Hover cards show scope and champion. Create cycle starts a draft cycle anchored on the standard from a published template (or empty). The cycle list and page are TASK-080 (built) | ROADMAP-013, TASK-086, DEC-029 |
| **Quality Management screens (TASK-080)** | Quality Management has Standards, Cycles and My work tabs (`?tab=`) and a cycle page. Cycles: list with filters (status, unit or program, template, anchor, late or due soon, only mine) and search, progress, next stage, unresolved-owner flag, Start, delete a draft (Trash, Undo), cancel with a reason. New cycle and the ⋯ menu's Create cycle share one dialog that shows the resolved unit and owner of every stage before it starts, flags what could not be resolved and lets a person choose. The cycle page shows the stages as a timeline and a list with inputs (missing ones flagged, never blocking; picker for document, evidence or standard), process and checklist, and outputs (note, document upload and download, approval decided only by the named approver as Internally approved / with conditions / Returned for changes, report stub with a manual mark-final); a return reopens the earlier stage; blank drafts are built by hand. My work lists my stages and approvals (count in the menu). Read-only for everyone else. The list API gained next stage, late and due flags and two filters | ROADMAP-013, TASK-080, DEC-029 |
| **Cycle plans, academic calendar and proposed runs (TASK-081)** | Settings -> Organization -> Institution -> Academic calendar holds the years and terms (dates, English and Arabic names; active ones of a kind never overlap). A cycle plan attaches a published template and a recurrence (every term, every N terms, every year, every N years, every N months, or when the previous one ends with the next date set by a decision) to an institution, unit, program, a whole standard (the IQF), a requirement or an evidence item, with a first start, a responsible unit and owner and "applies to" (kinds, program levels, unit types, an explicit list) narrowing the node's scope. Plans inherit: own, else (external standards) the first plan of the approved mapped IQF nodes, else the nearest ancestor's, else the whole standard's, labelled "Own", "From Standard 3", "From IQF 3.2"; Opt out stops a template at a node; Back to inherited removes the override. The ⋯ menu of every standard has "Set cycle plan…"; hover cards list the plans in effect; Quality Management has a Plans tab (next run, subjects covered, gaps) and the Cycles tab a "Due to launch" section computed on request: filters, select several and Review and launch in the shared launch dialog (plan, period and label recorded, previous run of the same plan found), or Skip this period with a reason. Where the calendar has no term for a period it says so and proposes nothing. Nothing launches by itself; notifications will hook in later | ROADMAP-013, TASK-081, DEC-029 |

## Built: Quality Management cycles, data and API (TASK-078; screens are TASK-080)

| Area | What works | Roadmap / tasks |
|---|---|---|
| **Cycles, stages, outputs, inputs** | A cycle is ordered stages with a responsible unit and an owner on the cycle and on every stage; a stage is inputs -> process -> outputs (report slot, uploaded document, note, approval). Cycles are launched from a published template or blank, about an anchor (institution, unit, program, standard version, requirement, evidence item, accreditation) with an optional subject; the template's rules find each stage's unit and owner in the org chart, and what they cannot settle is left empty and flagged. Stages start, complete (only when required outputs are final), skip with a reason and reopen; an approval is decided only by its named approver ("Internally approved", with conditions, or returned, which reopens the stage that made the work); inputs read an earlier stage, last year's cycle, or something picked. Drafts are deleted to the Trash, started cycles are cancelled with a reason; Undo, audit, `cycle:read` / `cycle:manage` / `cycle:work`, My work. API and typed web client only: no screens yet. Report outputs are a stub until the report engine (TASK-085) | ROADMAP-013, TASK-078, DEC-029 |
| **Cycle templates (Settings -> Quality Management)** | List (name EN/AR, anchors, version, status, stages; filter by status), new, duplicate, revise, retire and offer again, delete a never-published draft (Undo); editor with stages in order (names EN/AR, process, checklist, unit and owner rules, start and length in days, outputs and inputs), live plain-words checks, save unfinished, Publish that says what to fix, timeline preview, read-only view with "Revise to edit". Six shipped defaults as data (annual program report, periodic program review, administrative unit review, internal audit, course assessment, custom) added by "Add the default templates" / "Restore missing defaults". Read-only for everyone with org:read; editing needs cycle:manage | ROADMAP-013, TASK-079, DEC-029 |

## Built: org chart from an image (TASK-073)
