title: 'The syllabus is the course schema: a versioned, approved document with rules that flag but never block'
status: accepted
context: >-
  The AIU Course Syllabus Template (QAIEO guidance, Appendix 1) is the form every course already fills in. The owner
  (2026-11-09): the syllabus is the course schema, so implement it with import, export and an API to read and upsert. A
  policy register is a separate system, scoped and developed later.
decision: >-
  A syllabus is a versioned document per course: draft, in review, endorsed, approved, superseded. The instructor
  suggests, the course coordinator edits, the program chair reviews, the Dean approves; an approved version is locked by
  the database and its CLOs and CLO-to-PLO links become the course's current outcomes. Each CLO maps to one PLO with a
  required coverage level (Introduced, Reinforced, Mastered, in full); there are no SOs and no ILOs at course level. The
  minimum and maximum number of CLOs and of PLOs per course are settings. Each assessment maps to the CLOs it assesses,
  and each assessed CLO has a rubric. Rules never block an import, a parse or an API upsert: a syllabus that breaks one
  loads with its issues flagged. A syllabus with errors cannot be submitted for review, and it needs immediate attention
  from the course coordinator, then goes up the line (chair, Dean, VPAA) while it is unfixed. The sections, order and
  required flags are AIU's template as configuration that an admin can edit (amends DEC-037: the warehouse model builder
  stays in the BI; the syllabus template builder is the AMS's). Policies are not part of this: the syllabus will link to
  a policy register built separately.
rationale: >-
  One shared rule checker serves the screen, the import and the API, so a rule is written once. Flagging instead of
  blocking lets the existing syllabi come in as they are and shows each coordinator what to fix.
consequences: >-
  Open: how a course that serves several programs maps its CLOs (one PLO per program, or one in total) waits for
  approval from the higher authorities; until then a CLO maps to one PLO of one program. Out of scope for now: the
  policy section, course offerings, EDUVAL-only fields, AI parsing of Word syllabi.
