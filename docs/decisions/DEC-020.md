id: DEC-020
title: >-
  Data can be collected through forms, with an optional public link; responses join the data only when a person adds
  them
status: accepted
context: >-
  Data such as surveys and unit returns is collected from many people, inside and outside the institution, the way
  Google Forms does. The owner wants a built-in form builder with form and sheet views.
decision: >-
  A data item's columns are its form's questions. While the form is open, AMS users answer it signed in; the item's
  editors may also create a public link that anyone can use to answer, any number of times, until it is turned off or
  replaced. Each answer is kept as a response, checked with the same cell rules as the sheet. Responses become part of
  the data only when someone who may add evidence adds them, which saves the next version.
rationale: >-
  Collecting from people without accounts is the point of a form; holding responses apart keeps saved versions
  deliberate and reviewed.
consequences: >-
  A second unauthenticated write path next to DEC-018's one-time links: it only adds responses to one open form, is
  size-limited, audited, and closes when the form closes or the link is turned off.
