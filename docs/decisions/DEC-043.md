  Programs from documents match and update the programs that exist, by meaning, with a person confirming each match and

status: accepted
context: >-
  The owner (2026-11-18) asked whether dropping a document with program details on Programs > Docs would update existing
  programs. It did not: the import (TASK-076, v2) was create-only, matched by exact name and level, read few fields and
  dropped code, mode and years. The owner wants it intelligent: "ACCOUNTING Bac" existing and "Bachelor of Business
  Administration - Accounting" uploaded must be detected as the same; the AI proposes the mapping and the person
  confirms.
decision: >-
  The programs import reads in two steps. Each window of pages yields the facts it states about programs (name in
  English and Arabic, level, code, SIS code, unit, mode, credits, years, contact hours, language, mission, vision,
  discipline, each PEO and PLO), each with its quote. One organise call over all the facts of all the documents, shown
  the institution's programs (with their PEOs and PLOs) and its org chart, gives one item per program and decides by
  meaning which existing program it is, or that it is new, with a reason. A deterministic backstop matches the same code
  or name when the model did not, flagged. The review shows each proposal as "Updates CODE" or "New program"; its detail
  lets the person change the match and see each field and each PEO/PLO as now and as the document says, with a tick per
  change. Apply creates new programs (and units under their known parent) and updates matched ones: only the ticked
  fields that differ, PEOs and PLOs by code (added or their text updated), never deleting; a code another program holds
  is not taken; two items for one program are refused. Undo sets everything back (new programs, units and outcomes
  switched off) and Redo again, refused after a person's change. An edit re-runs the target's checks.
rationale: >-
  Program names vary between catalogues, handbooks and the SIS; exact matching makes duplicates. The model judges
  sameness, the person confirms, and nothing is written without a tick.
consequences: >-
  Migration 0082 lets the app set a proposal's flags. Prompts import_programs_facts v1 and import_programs_organise v1;
  v1/v2 stay for old runs, and v2 applies still undo. The same pattern is planned for courses from documents (record,
  placements, CLOs into the course draft).
